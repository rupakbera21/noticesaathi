# public/logo

This folder holds the logo files used in the app header.

- `logo-light.png` — displayed in light theme
- `logo-dark.png` — displayed in dark theme
- `logo-light@2x.png` — optimized 2x display copy for light theme header
- `logo-dark@2x.png` — optimized 2x display copy for dark theme header

Original source files are kept if under 500 KB each. Optimized copies are sized for the header at 2x pixel density. Only the active theme's logo is downloaded on first load.

Do not alter the artwork. If contrast fails, report it; do not recolor.
